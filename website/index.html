Light Doggo

An open-source quadruped robotics software project focused on simulation, kinematics, gait planning, trajectory generation and real-time control.

About

Light Doggo is designed around a simulation-first workflow, allowing robotics software to be developed and tested without continuously depending on physical hardware.

Features

Inverse kinematics
Gait and motion planning
Trajectory generation
MuJoCo simulation
CAN motor interfaces
Real-time visualization
