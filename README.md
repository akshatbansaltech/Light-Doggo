# MiceyMousey

a micromouse robot project — maze-solving robot with custom stm32f446 pcb + freertos firmware (GPLv2.1, based on an open-source IEEE Region 1 micromouse project)

- custom stm32f446 pcb + 26 custom symbols + 27 custom footprints
- freeRTOS firmware with own maze-solving algorithm
- everything open source, build it urself

see `MiceyMousey/README.md` for full layout
